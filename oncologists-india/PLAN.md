# План: онкологи Индии (лекарственная терапия) с имейлами

**Кого ищем:** медицинские онкологи (DM/DrNB Medical Oncology), онкогематологи / клинические гематологи,
детские онкологи. Лучевых терапевтов и хирургов-онкологов не берём.
**Ожидаемый объём:** ~2,5–4 тыс. человек (оценка; уточнится после сбора).

## Принципы
- Только открытые источники; соблюдаем robots.txt и условия сайтов, капчи и логины не обходим.
- Только профессиональные контакты. Даты рождения, домашние адреса и т.п. не собираем.
- У каждого имейла указан источник и год.
- Индийский закон о защите данных (DPDP Act 2023) не распространяется на данные, которые человек
  **сам сделал публичными** (ст. 3(c)(ii)). Поэтому основа базы — адреса, опубликованные самими врачами.
  Достроенные по схеме адреса — серая зона; делаем их только по согласованию с клиентом и помечаем отдельно.

## Проверенные источники (сентябрь 2026)

| Источник | Статус | Что даёт |
|---|---|---|
| **Europe PMC API** (статьи) | открыт, API | 8 306 статей 2016–2026 из индийских отделений медицинской/детской онкологии и онкогематологии; авторы, отделение, больница, город. 3 337 статей в открытом доступе — в полном тексте имейл автора для переписки (~80% статей в тесте) |
| **ISMPO — список членов** (ismpo.org) | открыт, robots разрешает | 806 членов общества медицинских и детских онкологов: имя + город. Костяк списка |
| **ClinicalTrials.gov API** | открыт | Контакты индийских центров международных исследований |
| **Сайты онкоцентров** (Tata Memorial, AIIMS, PGIMER, CMC Vellore, Apollo, HCG, Max, Fortis, Manipal и др.) | по robots.txt каждого | Текущее место работы, должность, иногда рабочий имейл |
| **OpenAlex** | открыт, API | Уточнение, где автор работает сейчас (без имейлов) |

**Не используем:**
- **CTRI** (индийский реестр исследований): в карточках есть имейлы исследователей, но поиск защищён капчей.
  Вариант — официальный запрос данных в ctri@gov.in или ручной поиск человеком.
- **WHO ICTRP**: robots.txt запрещает автоматический сбор.
- **NMC Indian Medical Register**: отдаёт дату рождения, имя отца, домашний адрес — такие данные не собираем.
- **Practo / JustDial / Lybrate**: условия сайтов запрещают сбор.

## Этапы
1. **Europe PMC, метаданные** — все статьи с индийскими аффилиациями «Medical Oncology / Haemato-oncology /
   Paediatric Oncology / Clinical Haematology / BMT» за 2014–2026 → кандидаты: имя, отделение, больница, город, год.
2. **Europe PMC, полные тексты (open access)** → имейлы авторов для переписки + имейлы в аффилиациях (PubMed).
3. **Склейка авторов** (одна запись на человека): имя + город/больница + имейл; учитываем индийские
   особенности имён (инициалы, перестановка имени и фамилии).
4. **ISMPO**: сопоставляем 806 членов с найденными; для ненайденных — отдельный поиск их статей по имени.
5. **ClinicalTrials.gov**: контакты индийских центров → дополнительные имейлы.
6. **Сайты онкоцентров** (топ-30): подтверждаем текущее место работы, добираем тех, кто не публикуется.
7. **(Опционально, по согласованию)** адреса по схеме доменов больниц (tmc.gov.in, aiims.edu и т.п.) с пометкой.
8. **Итоговая таблица** + проверка имейлов сервисом перед рассылкой.

## Итоговая таблица
Имя · специальность (отделение) · больница · город · штат · последний год публикации · число статей ·
член ISMPO · email · тип (опубликован сам / из исследований / схема) · источник · год · другие адреса.

## Итоги разведки и первого прогона (26.09.2026)
- Europe PMC: 10 412 статей 2014–2026 из индийских онкоотделений; скачано 4 208 полных текстов.
- В полных текстах 86% имейлов удаётся привязать к конкретному автору, но автором для переписки часто
  оказывается соавтор-неонколог → добавлен адресный поиск по каждому врачу (этап 5).
- **74% опубликованных адресов — бесплатная почта** (gmail, yahoo, hotmail, rediffmail). Их нельзя
  достроить по схеме, поэтому этап 7 (схемы доменов) для Индии даёт мало: имеет смысл только для
  tmc.gov.in / actrec.gov.in, aiims.edu, manipal.edu, cmcvellore.ac.in, pgimer.edu.in и т.п.
- Сайты сетей: Apollo, Fortis, AOI, Yashoda блокируют роботов (403) — не трогаем. HCG, Max, Manipal,
  Medanta, Narayana, RGCI, Tata Memorial доступны (с ограничениями robots.txt) — источник имён без имейлов.
- CTRI: подготовлен официальный запрос данных (CTRI_REQUEST.md).
