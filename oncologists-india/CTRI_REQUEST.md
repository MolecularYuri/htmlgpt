# Письмо в CTRI (Clinical Trials Registry – India) — запрос данных

**Кому:** ctri@gov.in
**Тема:** Request for bulk export of registered oncology trials (public fields)

---

Dear CTRI team,

We are compiling a directory of clinical investigators working in medical oncology, haemato-oncology
and paediatric oncology in India, based on publicly available registry information.

Could you please share a bulk export (CSV/Excel) of trials registered in CTRI with an oncology health
condition (ICD-10 chapter C / D00–D48), including the public fields already shown on each trial page:
CTRI number, public title, recruitment status, sponsor, and the contact details of the Principal
Investigator, Scientific Query contact and site investigators (name, designation, affiliation, city, email).

If a bulk export is not possible, we would be grateful for guidance on the permitted way to access
this public information without repeated manual searches.

We will use the data only for professional communication with investigators, and will honour any
opt-out requests.

Kind regards,
[Имя, организация, контакты]
